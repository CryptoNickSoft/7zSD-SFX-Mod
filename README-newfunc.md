# 7zSFX — новые функции (патч NEW FUNCTIONS)

Версия 1.8.0 port (сборка 4000). Шесть новых функций, добавленных к модулям
7zSD из этого репозитория. Все они управляются параметрами конфигурации
(тот же синтаксис `Имя="значение"`, что и остальные параметры 7zSD) либо
переопределяются из командной строки.

## 1. LogFile — журнал работы

Параметр: `LogFile="путь"`

Модуль пишет в указанный файл (UTF-8, режим дозаписи) шаги работы:
- `[extract] OK` / `[extract] retry` / `[extract] FAILED` — извлечение;
- `[run] executing batch` — запуск команд;
- `[done] OK` — успешное завершение;
- `[crc] ...` — диагностика контроля целостности.

Подавляется битом 8 параметра `CleanMode`.

## 2. RetryAttempts — повторы извлечения

Параметр: `RetryAttempts="N"` (целое)

Число повторных попыток извлечения при сбое (например, из-за временной
блокировки файла антивирусом или системой). После `N` неудачных попыток
модуль завершается с кодом возврата `8`. Значение по умолчанию — 0 (без
повторов).

## 3. Language — принудительный язык интерфейса

Параметр: `Language="1049"` или `Language="0x419"`

Code локали (десятичный или шестнадцатеричный), который модуль применяет
для текстов диалогов и кнопок до первого обращения к строкам. Примеры:
- `1049` / `0x419` — русский;
- `1033` / `0x409` — английский.

## 4. PayloadCRC — контрольная сумма полезной нагрузки

Параметр: `PayloadCRC="0x..."`

Модуль вычисляет CRC32 блока 7z — от последней сигнатуры
`37 7A BC AF 27 1C` до конца файла — и сравнивает с заданным значением.
Если контрольные суммы не совпадают, установка прерывается с кодом
возврата `8` (в скрытом режиме диалог ошибки не показывается).

Если параметр не задан или равен `0`, проверка отключена — архив не
проверяется и распаковывается как обычно.

## 5. Переопределение параметров из командной строки

Формат: `-Ключ="значение"`

Для параметров `LogFile`, `RetryAttempts`, `Language`, `PayloadCRC`
значения можно передать напрямую в командной строке при запуске SFX:

```
installer.exe -y -InstallPath="C:\App" -Language="1033"
installer.exe -PayloadCRC="0x11223344"
```

Одноимённые параметры в файле конфигурации при этом переопределяются. Важно:
`-PayloadCRC=` не путается с паролем `-p...` — пароль обрабатывается только
если после `p`/`P` не идёт `ayload`.

## 6. CleanMode — мало-следовый режим очистки

Параметр: `CleanMode="маска"` (битовая маска)

| Бит | Значение | Действие |
|-----|----------|----------|
| 1   | 1        | Скрытное самоудаление exe после работы (невидимый .cmd-хелпер + страховка на перезагрузку) |
| 2   | 2        | Дозачистка временной папки после извлечения |
| 4   | 4        | Перезапись файла нулями перед удалением (анти-восстановление) |
| 8   | 8        | Не оставлять служебных следов (подавляет журнал даже при заданном LogFile) |

Значения складываются: `CleanMode="7"` = 1+2+4, `CleanMode="15"` = всё.

## Коды возврата

- `0` — успех;
- `8` — ошибка целостности payload (PayloadCRC) либо исчерпаны попытки
  извлечения (RetryAttempts);
- прочие ненулевые — сбои извлечения/конфигурации (стандартные коды 7zSD).
