Публикация проекта на GitHub (пошагово)
=======================================

Подготовлено: папка "publish_7zsfx" — готовая для публикации структура.
git/gh на этой машине не установлены, поэтому публикация делается
через браузер (у вас есть Edge).

--------------------------------------------------------------------------
ШАГ 1. Войдите в GitHub
--------------------------------------------------------------------------
Откройте в Edge:  https://github.com/login
Войдите в свой аккаунт (если нет — зарегистрируйтесь).

--------------------------------------------------------------------------
ШАГ 2. Создайте новый репозиторий
--------------------------------------------------------------------------
1. Перейдите на: https://github.com/new
   (или в правом верхнем углу: "+" -> "New repository")
2. Заполните:
   - Repository name: 7zsfx          (или любое своё имя)
   - Description: Modified 7-Zip SFX module (1.8.0.4000)
   - Visibility: Public  (вы выбрали публичный)
   - НЕ отмечайте "Add a README", ".gitignore" или "license" сейчас —
     они уже есть в папке. Пустой репозиторий.
3. Нажмите "Create repository".

--------------------------------------------------------------------------
ШАГ 3. Загрузите файлы
--------------------------------------------------------------------------
Вариант А (проще, рекомендую):
1. На странице нового (пустого) репозитория нажмите
   "uploading an existing file" (ссылка "uploading ... file").
2. Откройте Проводник, папку:  publish_7zsfx
3. Выделите ВСЁ внутри неё (Ctrl+A) и перетащите в браузер,
   ИЛИ нажмите "choose your files" и выберите.
4. Внизу введите короткое описание коммита:
   "Initial import: 7zSFX modified module 1.8.0.4000"
5. Убедитесь, что выбрана ветка main, нажмите "Commit changes".

Вариант Б (все файлы одним архивом):
1. Заархивируйте publish_7zsfx в .zip (у вас есть 7-Zip),
   загрузите как описано выше, затем отдельно распакуйте.

Подсказка: проще всего открыть саму папку publish_7zsfx, выделить всё и
перетащить в окно браузера на странице загрузки.

--------------------------------------------------------------------------
ШАГ 4. Проверьте результат
--------------------------------------------------------------------------
Откройте https://github.com/<ваш-логин>/7zsfx
Должны отобразиться: README.md (подробно), структура папок,
README-build.txt / README-loader.md / README-password.md, LICENSE.md.

--------------------------------------------------------------------------
Возможные нюансы
--------------------------------------------------------------------------
- GitHub не разрешает файл больше 100 МБ по отдельности; у нас в папке
  файлы маленькие (10,2 МБ всего), поэтому ограничений нет.
- Секреты/пароли: в исходниках паролей нет. Если когда-либо добавите
  реальные секреты — НЕ коммитьте их.
- Папки Intermediate / build (временные объекты сборки) в публикацию
  НЕ включены — в репозитории их быть не должно (см. .gitignore).

Готово. После публикации можете склонировать репозиторий на другую машину
или продолжить работать локально, используя git.
