Сборка 7zSFX 1.8.0.4000 с параметром Password
==========================================

Что сделано
-----------
В исходники авторского модуля (7zsd_src_170_3900) добавлен параметр конфигурации
Password="..." — пароль для зашифрованного архива, который не запрашивается
у пользователя при запуске.

Правка 1 — sources/7zSfxMod.h, блок SFX_CRYPTO:

    #define CFG_PASSWORD                _CFG_PARAM_TYPE"Password"
    #define CFG_PASSWORD_TITLE          _CFG_PARAM_TYPE"PasswordTitle"

Правка 2 — sources/main.cpp, SetConfigVariables(), блок SFX_CRYPTO
(рядом с разбором PasswordTitle):

    // password from config (command line '-p' has priority)
    if( CSfxArchive::CPassword::IsDefined() == false )
    {
        if( (lpwszValue = GetTextConfigValue(CFG_PASSWORD)) != NULL && lpwszValue[0] != L'\0' )
            CSfxArchive::CPassword::Set( lpwszValue );
    }

Почему так: SetConfigVariables() вызывается до gSfxArchive.Open() (main.cpp:765-769),
поэтому пароль успевает примениться до открытия архива. Если пароль уже задан
ключом -p, значение из конфига игнорируется (ключ имеет приоритет, как и у
остальных параметров).

Готовые модули: dist_password\\ (12 файлов), архив 7zsd_180_4000_password.7z.
Непропатченный набор остался в dist\\ (сборка из исходников без изменений).

Как пользоваться
----------------
1) Создать зашифрованный архив (пароль тот же, что будет в конфиге):

    7z a -t7z -m0=lzma2 -mx=9 -mhe=on -p"Секрет" payload.7z "C:\\App\\*"

   -mhe=on шифрует и имена файлов (необязательно, но логично).
   Для модулей 7zsd_Deflate.sfx / 7zsd_PPMd.sfx архив нужно делать с -mhc=off,
   иначе заголовок не распакуется (это ограничение методов, не патча).

2) Конфигурация config.txt (UTF-8, без BOM):

    ;!@Install@!UTF-8!
    Title="Установка MyApp"
    Password="Секрет"
    GUIMode="2"
    InstallPath="%PROGRAMFILES%\\MyApp"
    RunProgram="setup.exe /S"
    ;!@InstallEnd@!

3) Склеить модуль + конфиг + архив:

    copy /b 7zsd_All.sfx + config.txt + payload.7z setup.exe

   (или: cmd /c copy /b ... — важно именно склеивание, а не 7z -sfx)

4) Запуск: setup.exe — пароль не спрашивается, архив распаковывается в
   InstallPath и выполняется RunProgram. Ключ -p при этом не нужен.

Поведение (проверено)
---------------------
  Password в конфиге | ключ -p     | результат
  -------------------+-------------+-------------------------------------------
  нет                | нет         | диалог ввода пароля (как раньше)
  верный             | нет         | распаковка без диалога
  верный             | верный      | распаковка без диалога
  неверный           | нет         | ошибка, модуль снова показывает диалог
  неверный           | верный      | успех: -p приоритетнее конфига
  верный             | неверный -p | ошибка (ключ приоритетнее)

Особенности формата
-------------------
- Пробелы в пароле: Password="pa ss" — работает.
- Обратный слэш удваивается: пароль pa\\ss пишется как Password="pa\\\\ss"
  в файле (то же правило, что у путей InstallPath).
- Кириллица работает (конфиг UTF-8, с BOM и без).
- Символ " внутри значения записать нельзя — для таких паролей используйте -p.

Ограничения
-----------
- Если конфиг положен внутрь зашифрованного архива (compressed config),
  модуль не сможет прочитать Password до открытия архива — там нужен -p
  или диалог. Штатная схема (конфиг после stub'а, как в примере) работает.
- Значение параметра хранится в конфиге открытым текстом.

Безопасность
------------
Это удобство, а не защита. Пароль читается из готового setup.exe:

    setup.exe -sfxconfig dumped.txt      -> в dumped.txt виден Password="..."
    (проверено на собранном модуле)

Плюс сама полезная нагрузка извлекается как обычный 7z-архив (7z x setup.exe).
Реальная защита — только когда пароль не хранится в файле: ввод в диалоге,
ключ -p из защищённого источника или шифрование данных вне SFX.

Результаты тестов (см. smoke_password.ps1)
------------------------------------------
Зашифрованные архивы (-mhe=on) + Password в конфиге, 12 модулей x86/x64:
все вернули код 0, распаковали оба файла и выполнили RunProgram.
Отдельно: регрессия на незашифрованных архивах (smoke.ps1) — все 12 модулей
проходят; отсутствие Password не меняет прежнее поведение.

Пересборка
----------
  build.cmd x86 All          (и остальные: Base/LZMA/LZMA2/Deflate/PPMd, x64)
Заголовок изменился, поэтому перед пересборкой нужно удалить src\\Intermediate,
иначе nmake не увидит зависимость от .h (в makefile нет dep-файлов).
