1.8.0 port + NEW FUNCTIONS (сборка 4000) 20.11.2026
# Шесть новых функций из dev-проекта, включённых в основные модули (см. README-newfunc.md)
+ Параметр 'LogFile' - журнал работы (UTF-8, append): шаги извлечения/запуска/диагностика CRC
+ Параметр 'RetryAttempts' - число повторов извлечения при сбое; по исчерпании - код возврата 8
+ Параметр 'Language' - принудительный язык UI (десятичный или hex код локали, напр. 1049 / 0x419)
+ Параметр 'PayloadCRC' - контрольная сумма блока 7z (CRC32); несовпадение прерывает установку (код 8); 0/нет - отключено
+ Переопределение параметров из командной строки: -Ключ="значение" для LogFile/RetryAttempts/Language/PayloadCRC
+ Параметр 'CleanMode' (битовая маска): 1=самоудаление exe, 2=дозачистка temp, 4=перезапись файла нулями, 8=подавление лога
* Коды возврата: 0 - успех, 8 - ошибка целостности payload / исчерпаны попытки извлечения
