Модифицированный 7zSFX — русский комплект
Версия модуля: 1.8.0 develop, сборка 4000 (ядро 7-Zip 26.06)

Состав комплекта
  7zsd.sfx, 7zsd_x64.sfx          — базовые модули, Copy и LZMA (x86 / x64)
  7zsd_LZMA.sfx и _x64            — метод LZMA
  7zsd_LZMA2.sfx и _x64           — метод LZMA2
  7zsd_Deflate.sfx и _x64         — метод Deflate
  7zsd_PPMd.sfx и _x64            — метод PPMd
  7zsd_All.sfx и _x64             — все методы
  7zSD_RU_plus.chm                — русская справка (HTML Help)
  7zSD_RU_plus.txt                — та же справка текстом (UTF-8)
  example\                        — рабочий пример лоадера

Быстрый старт
  1. Создайте архив payload.7z с файлами установки. Метод сжатия
     должен поддерживаться модулем: базовый 7zsd.sfx — Copy и LZMA,
     для LZMA2/Deflate/PPMd берите профильный модуль или All.
  2. Подготовьте loader.txt (Title, при необходимости Password).
     Для кириллицы файл в UTF-8, первая строка ;!@Install@!UTF-8!,
     последняя — ;!@InstallEnd@!.
  3. Склейте: copy /b 7zsd.sfx + loader.txt + payload.7z loader.exe
  4. Запустите: loader.exe payload.7z (или перетащите архив на loader.exe).

Отличия этой сборки от официальной 1.7/3900
  • Password="..." — пароль архива, диалог не показывается.
  • SfxAuthor="..." — код автора; если Password не задан,
    код используется как пароль архива (как в официальном модуле).
  • Archive="..." — необязательный путь к внешнему архиву;
    аргумент командной строки имеет приоритет.
  • Режим лоадера: архив передаётся аргументом или перетаскиванием.
  • Конфигурация может лежать внутри архива (*.sfx.config*).

  Однократный запуск и уникальные папки
    • SingleInstance="1" — если первая копия уже работает с той же
      папкой InstallPath, вторая копия сразу выходит (код 0), ничего
      не распаковывая и не удаляя.
    • SingleInstance="2" — вторая копия активирует окно первой и выходит.
    • SingleInstance="0" — поведение прежних версий (по умолчанию).
    • %SfxVarPID% (или %%PID%%) в InstallPath, RunProgram, Delete и других
      раскрываемых параметрах — идентификатор процесса. Позволяет
      распаковывать каждую копию в отдельную папку.
    • Папка распаковки удаляется ограниченным числом попыток (около
      секунды): свободные файлы удаляются, занятый файл и папка
      остаются — минутного ожидания больше нет.

Исправление конфликта двух одновременных копий
  • Временная папка распаковки теперь УНИКАЛЬНАЯ: имя строится
    как <PID в base36>.<счётчик в base36> — короткое, без ведущих
    нулей и без лишних суффиксов. Две одновременно запущенные копии
    SFX не работают в одну папку, и очистка одной не задевает файлы
    другой.
  • Файлы, которые держит другой процесс, при удалении пропускаются
    (проверка SfxIsFileBusyForDelete) — запущенная программа не ломается.
  • Если %TEMP% недоступен, используется %LOCALAPPDATA%\7zSFX_Temp;
    запасная папка автоудаляется, когда становится пустой.

Важно о безопасности
  Пароль в конфигурации хранится открытым текстом и виден через
  -sfxconfig; код SfxAuthor детерминирован и не является защитой.
  Используйте эти параметры для удобства, а не для секретности.

Справка
  CHM открывается двойным щелчком. Если Windows блокирует файл,
  снимите галочку «Разблокировать» в свойствах файла.
  TXT — та же справка без оглавления, в кодировке UTF-8.
