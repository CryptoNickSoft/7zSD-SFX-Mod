Комплект модулей 7zSFX 1.8.0.4000 с внешним архивом
================================================

Что это
-------
12 модулей (x86 и x64) с доработками исходников:

1. Password="..."     — пароль архива берется из конфига лоадера,
                        диалог ввода не показывается;
2. Archive="..."      — необязательный запасной путь к внешнему архиву;
3. аргумент запуска   — путь к архиву передается лоадеру:
                        loader.exe archive.7z или перетаскиванием файла.

Модуль больше не требует склеивания с архивом: архив лежит отдельным файлом,
а внутри архива находится конфиг сценария установки (*.sfx.config.*).

Исправление конфликта двух одновременных копий
-----------------------------------------------
- Временная папка распаковки теперь УНИКАЛЬНАЯ: имя строится
  как <PID в base36>.<счётчик в base36> — короткое, без ведущих
  нулей и без лишних суффиксов. Две одновременно запущенные копии
  SFX больше не работают в одну папку, и очистка одной не задевает
  файлы другой.
- Не заданный InstallPath считается временной папкой, как прежде,
  но имя папки уникально для каждого запуска.
- Удаление файлов больше не сносит принудительно файлы, которые
  держит другой процесс: SfxIsFileBusyForDelete пропускает такие
  файлы, не ломая запущенную программу.
- Если %TEMP% недоступен, используется запасная папка
  %LOCALAPPDATA%\7zSFX_Temp; она автоудаляется, когда становится пустой.

Непропатченные наборы: dist\ (исходная сборка), dist_password\ (только Password).

Как собрать лоадер
------------------
    copy /b 7zsd_LZMA2.sfx + loader.txt loader.exe

loader.txt (минимум):

    ;!@Install@!UTF-8!
    Password="Pass123"
    ;!@InstallEnd@!

Необязательно: Title="..." и GUIMode="2" — они нужны только для окон,
которые могут появиться до чтения конфига из архива (ввод пароля, ошибки).

Как пользоваться
----------------
    loader.exe payload.7z
    loader.exe "D:\distr\app v2.7z"
    перетащить payload.7z на loader.exe

Можно держать рядом много архивов и запускать нужный; ключи модуля
(-y, -gm2 и т.д.) сочетаются с путем: loader.exe -y payload.7z.
Путь, переданный аргументом, в RunProgram не попадает.

Сценарий установки — внутри архива, файл с именем *.sfx.config или
*.sfx.config.*, например app.sfx.config.txt:

    ;!@Install@!UTF-8!
    Title="Установка MyApp"
    GUIMode="2"
    InstallPath="%PROGRAMFILES%\\MyApp"
    RunProgram="setup.exe /S"
    ;!@InstallEnd@!

Этот файл не распаковывается на диск: модуль читает его и пропускает.

Архивы
------
   7z a -t7z -m0=lzma2 -mx=9 -mhe=on -p"Pass123" payload.7z .\files\*

  - метод должен поддерживаться выбранным модулем (см. таблицу выше);
  - -mhe=on шифрует имена файлов (необязательно);
  - для 7zsd_Deflate / 7zsd_PPMd добавляйте -mhc=off, иначе заголовок
    архива не распакуется;
  - 7zsd_All принимает любой из методов.

Пароль
------
Латиница/цифры; не используйте " и !; обратный слэш удваивается (\\).
Кириллицу в пароле bat-сборщик может исказить, если читает конфиг.

Ограничения и безопасность
--------------------------
- payload.7z лежит отдельно и может быть подменен — при необходимости
  проверяйте хэш/подпись до распаковки (в модуле такой проверки нет).
- Пароль хранится в loader.exe открытым текстом: loader.exe -sfxconfig dump.txt
  покажет его. Это удобство, а не защита от распаковки.
- Без аргумента и без Archive= модуль работает как обычный SFX и ищет архив
  внутри себя.

Проверка комплекта
------------------
smoke_loader_all.ps1: для каждого из 12 модулей собран лоадер (модуль +
конфиг с паролем), запущен с внешним зашифрованным архивом (-mhe=on) по
аргументу. Результат: у всех код 0, файлы распакованы, RunProgram выполнен,
разрядность PE совпадает с именем. Итог: LOADER SET: ALL PASSED.
